# Air Quality Forecast

EDA and monthly air-quality forecast (AQI and five pollutants) by city clusters.

## Repository layout

| Directory | Purpose |
|-----------|---------|
| `train_model/chaos/experiments.ipynb` | EDA, clustering, model selection (§1–8) |
| `train_model/chaos/notebook_utils.py` | Notebook helper functions |
| `train_model/src/trainer.py` | Full training pipeline + sync to backend |
| `train_model/src/cluster_forecast/` | Forecast package: clustering, CV, models, artifacts |
| `train_model/scripts/sync_inference_to_backend.py` | Copy inference code into `backend/src/predictor/forecasting/` |
| `train_model/models/` | Training artifacts (`.joblib`, JSON, CSV) |
| `backend/` | FastAPI: city → cluster → forecast from saved model |
| `backend/src/predictor/forecasting/` | Synced inference (generated by sync script) |
| `frontend/` | Streamlit UI |
| `docker-compose.yaml` | Backend + frontend; models mounted from `train_model/models/` |

## `cluster_forecast` package

Shared logic for the notebook, `trainer.py`, and (partially) the backend.

```
train_model/src/cluster_forecast/
├── config.py          # constants, ModelConfig, hyperparameter grids
├── clustering.py      # city profile, KernelPCA + KMeans, A/B groups (ARCH)
├── panel.py           # monthly cluster panel
├── features.py        # lags and recursive multi-output
├── intervals.py       # min/max bands (const / √h)
├── models/            # Seasonal Naive, Holt–Winters, Ridge / WLS / GB
├── predict.py         # single forecast entry point by configuration
├── cv.py              # expanding CV with linear fold weights
├── selection.py       # §6.4.1 tune + §6.4.2 select_models_weighted_cv
├── artifacts.py       # build_cluster_artifact, forecast_panel_with_intervals
├── inference.py       # forecast_from_artifact (.joblib load only)
├── training.py        # train_cluster_models → models/
└── interpret.py       # human-readable summaries for the notebook
```

Import in the notebook and scripts (API unchanged):

```python
import cluster_forecast as cf

df, city_profile = cf.assign_city_clusters(df, n_clusters=8)
_, tuned = cf.tune_hyperparams_weighted_cv(df, target_columns)
selection = cf.select_models_weighted_cv(df, target_columns, tuned_by_cluster=tuned, ...)
cf.train_cluster_models(df, city_profile, models_dir, model_by_cluster=selection)
```

## Training and deployment

From `train_model/`:

```bash
poetry install
poetry run python src/trainer.py
```

`trainer.py` runs in order (with stage logs to the console):

1. load data and cluster cities;
2. residual groups A/B (ARCH);
3. hyperparameter tuning (§6.4.1) — usually the slowest step;
4. model-type selection via weighted CV (§6.4.2);
5. fit on full history and save `cluster_*__multioutput.joblib`;
6. copy artifacts to `backend/models/`;
7. **automatic** run of `scripts/sync_inference_to_backend.py` (inference code into backend).

Docker (from repo root):

```bash
docker compose up --build
```

- API: http://localhost:8000  
- UI: http://localhost:8501  

Backend container models: volume `./train_model/models:/app/models`.

Manual inference sync (if only forecast code changed, without retraining):

```bash
python scripts/sync_inference_to_backend.py
```

## Processing notes

- Observations are **monthly**; forecast step is calendar month (`MS`).
- `AQI_Bucket` is derived from numeric AQI; separate bucket EDA is not required.
- Each city maps to one `cluster_id` by full profile; forecast uses the cluster aggregate series.
- Five model types per cluster; selection by **MAE** (weighted expanding CV, 4 folds).
- Assumptions and limitations — `experiments.ipynb`, section 8.
